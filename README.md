
Aplicação das Heurísticas de Nielsen

Heurística #1 - Visibilidade do Status do Sistema:
- Implementada através das mensagens de progresso:
  "[Passo 1 de 3]", "[Passo 2 de 3]" e "[Passo 3 de 3]"
- O usuário sempre sabe em qual etapa do pedido está.

Heurística #3 - Controle e Liberdade do Usuário:
- O usuário pode digitar "voltar" para retornar à etapa anterior.
- Pode digitar "cancelar" a qualquer momento para encerrar o pedido.

Heurística #9 - Ajuda no Reconhecimento e Diagnóstico de Erros:
- Mensagens de erro claras e específicas.
- Exemplo: "Código 99 não encontrado. Nossos códigos vão de 1 a 10."
- Tratamento de entrada inválida com int.TryParse para evitar falhas.
